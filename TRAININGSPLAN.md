# Entwurf: Trainingsplan und App

Stand: 14.10.2026 · für Timo (37 J., 190 cm, 92 kg, Wiedereinsteiger)
Ziel: Muskelaufbau + Abnehmen · 3x pro Woche ca. 60 min · Rücken unten etwas empfindlich

## 1. Ausrüstung

Vorhanden: Klimmzugstange, Widerstandsbänder, verstellbare Hantelbank, Kurzhanteln 2,5 / 5 / 7,5 / 10 / 12,5 kg.

**Engpass:** Für Beine, Rücken und Brust sind 12,5 kg pro Hand schnell zu leicht. Oberkörper-Isolationsübungen (Seitheben, Curls, Trizeps) passen dagegen gut.

**Empfehlung zum Kaufen (nach Priorität):**
1. **Verstellbare Kurzhanteln bis ca. 24–32 kg** (Scheiben- oder Schnellverstellsystem). Das bringt am meisten, vor allem für Beine und Rudern.
2. **Ein paar stärkere Widerstandsbänder** (Loop-Bänder bis ca. 30–50 kg Zug), auch als Hilfe bei Klimmzügen.
3. Optional später: Gewichtsweste (für Klimmzüge, Liegestütze, Kniebeugen).

Bis dahin funktioniert der Plan trotzdem: Wir arbeiten mit höheren Wiederholungen, langsamem Tempo, einbeinigen Übungen und Pausen am tiefsten Punkt.

## 2. Trainingsplan: Ganzkörper A / B / C mit Arm-Fokus

3 Tage, z. B. Mo / Mi / Fr. Jede Einheit: 5–8 min Aufwärmen, Hauptübungen mit 60–90 s Pause, am Ende ein **Arm-Supersatz** (Bizeps und Trizeps im Wechsel, kaum Pause dazwischen, spart Zeit).
Rückenschonend: kein schweres Vorbeugen mit Rundrücken, Rumpf-Stabi in jeder Einheit.

**Arm-Fokus:** Bizeps und Trizeps bekommen in jeder Einheit eigene Übungen, zusammen ca. 9–10 direkte Sätze pro Woche je Muskel. Dazu kommen Klimmzüge/Chin-ups und Rudern (Bizeps) sowie Drückübungen und enge Liegestütze (Trizeps). Für Arme reichen deine Hanteln anfangs gut aus.

**Tag A**
| Übung | Sätze × Wdh. |
|---|---|
| Goblet Squat (Kurzhantel vor der Brust) | 3 × 10–15 |
| Kurzhantel-Bankdrücken flach | 3 × 8–12 |
| Klimmzüge (bei Bedarf mit Band) | 3 × 5–10 |
| Glute Bridge / Hip Thrust auf der Bank | 3 × 12–15 |
| Seitheben | 3 × 12–15 |
| Supersatz: Bizeps-Curls stehend + French Press liegend (Bank) | 3 × 10–12 je |
| Dead Bug | 3 × 8 pro Seite |

**Tag B**
| Übung | Sätze × Wdh. |
|---|---|
| Bulgarian Split Squat (Bank) | 3 × 8–12 pro Bein |
| Schrägbankdrücken Kurzhantel | 3 × 8–12 |
| Einarmiges Kurzhantel-Rudern auf der Bank | 3 × 10–12 pro Seite |
| Rumänisches Kreuzheben Kurzhantel (leicht, gerader Rücken) | 3 × 12–15 |
| Face Pulls mit Band | 3 × 15 |
| Supersatz: Hammer-Curls + Trizeps-Kickbacks | 3 × 10–12 je |
| Bird Dog | 3 × 8 pro Seite |

**Tag C**
| Übung | Sätze × Wdh. |
|---|---|
| Ausfallschritte rückwärts | 3 × 10 pro Bein |
| Schulterdrücken sitzend (Bank aufrecht) | 3 × 8–12 |
| Chin-ups (Untergriff, bei Bedarf mit Band) | 3 × 5–10 |
| Enge Liegestütze (Trizeps-Fokus, ggf. erhöht) | 3 × max |
| Supersatz: Seitheben + Face Pulls mit Band | 3 × 12–15 je |
| Supersatz: Schrägbank-Curls (Bank ca. 45°) + Trizeps Überkopf Kurzhantel | 3 × 10–12 je |
| Finisher: Bizeps-Curls mit Band + Trizeps-Pushdown mit Band (an der Klimmzugstange) | 2 × 15–20 je |
| Seitstütz | 3 × 20–30 s pro Seite |

Seitheben (für breitere Schultern) und Face Pulls (hintere Schulter, gesunde Haltung) sind je 2× pro Woche dabei. Eine Einheit dauert dadurch eher 60–75 min.

Abnehmen kommt vor allem über die Ernährung (leichtes Kaloriendefizit, viel Eiweiß). Zusätzlich hilft tägliches Gehen.

## 3. Steigerungsregel (Basis für die automatischen Vorschläge)

**Doppelte Progression:**
- Jede Übung hat einen Wiederholungsbereich, z. B. 8–12.
- Schaffst du **in allen Sätzen das obere Ende** (z. B. 3 × 12) sauber, schlägt die App beim nächsten Mal das **nächste Gewicht** vor (z. B. 10 → 12,5 kg) und startet wieder unten im Bereich.
- Schaffst du es nicht, bleibt das Gewicht und die App zielt auf +1 Wiederholung.
- Ist das schwerste Gewicht erreicht, schlägt die App **mehr Wiederholungen, langsameres Tempo oder eine schwerere Variante** vor (z. B. Goblet Squat → Bulgarian Split Squat).
- Bei Klimmzügen/Liegestützen: Wiederholungen steigern, dann Band schwächer wählen bzw. weglassen.
- Fallen die Wiederholungen zwei Einheiten hintereinander ab, schlägt die App eine leichtere Woche vor (Deload).

Die App kennt deine verfügbaren Gewichte und schlägt deshalb nur Gewichte vor, die du wirklich hast. Wenn du neue Hanteln kaufst, trägst du sie einfach nach.

## 4. Die App

**Art:** Web-App (PWA), die du auf dem iPhone über Safari „Zum Home-Bildschirm“ installierst. Sie läuft danach wie eine App, funktioniert offline, und alle Daten bleiben auf dem Handy. Export/Import als Datei für Backups.

**Bildschirme**
1. **Heute:** Welches Training ist dran (A/B/C). Pro Übung der Vorschlag (Gewicht × Wdh.), große Felder zum Eintragen von Wiederholungen und Gewicht pro Satz, Haken pro Satz, Notizfeld. Werte vom letzten Mal stehen daneben.
2. **Plan:** Übungen, Sätze, Wiederholungsbereiche ansehen und ändern, Übungen austauschen.
3. **Fortschritt:** Diagramm pro Übung (Gewicht, Wiederholungen, Volumen), Bestleistungen, Trainingskalender.
4. **Körpergewicht:** Gewicht eintragen, Verlauf als Diagramm mit Trendlinie.
5. **Einstellungen:** Meine Geräte und Gewichte, Backup exportieren/importieren.

**Technik:** React + TypeScript mit Vite, Daten in der lokalen Datenbank des Browsers (IndexedDB). Code liegt in deinem Ordner `Traniningsapp`.

**Wichtig fürs iPhone:** Damit du die App installieren kannst, muss sie über eine HTTPS-Adresse erreichbar sein. Einfachste kostenlose Lösung: GitHub Pages (dein GitHub-Konto, die Daten bleiben trotzdem nur auf deinem Handy).
